Importin

A read-only MCP server for Apple Mail

Importin reads what Mail.app already keeps on your Mac and gives an AI agent six tools to find and read it, S/MIME-encrypted messages included. It cannot send, move, flag or delete mail.

DownloadChoose the zip for Apple Silicon or for Intel. Apple has not notarised the binary, so macOS refuses it the first time; one command clears that (Install). You can also build it from source.

How it works

Mail’s own files
Searches by header go to the Envelope Index, Mail’s SQLite database. Bodies and attachments come from the .emlx message files and the attachments Mail stores beside them. Importin reads both where Mail keeps them, in ~/Library/Mail, so there is no index to build, no watcher and no network.
Six tools
The agent can find messages by sender, recipient, Cc, subject, date, mailbox or words in the body. It can read a message with its To, Cc and Bcc, its thread, or an attachment as text, and list mailboxes and accounts.
S/MIME
Encrypted messages are decrypted per request, by default with the key in your keychain. The plaintext exists only in the response and is never written to disk.
Read-only
No code path sends, moves, flags or deletes mail, and a test checks the source to keep it that way.

Lemna

A quiet place to write without stopping.

Summon it over any app with ⌃⌥Space and write forward for as long as you like; the text glides past the caret. ⌘⏎ puts all of it into that app.

DownloadThe app is self-signed, not notarized: right-click it and choose Open the first time.

  • Every key is kept in an encrypted journal on your Mac until the text has gone out.
  • Nothing leaves your Mac: no network, no account, no telemetry.

Moin Journal

A private journal for the Mac, kept as files in a folder you own.

  • Entries are Markdown files and media are plain files, all in a folder you choose; the default is ~/Moin Journal.
  • A journal exported from another app comes in with its media; running the import again finishes the rest without making duplicates.
  • There is no AI, no telemetry and no server of ours. The Mac app comes first; iPhone and Windows versions are planned.
